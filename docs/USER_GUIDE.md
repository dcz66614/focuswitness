## 1. 产品概述与科学定位

**P007 焦证仪 (FocusWitness)** 是一套用于光学远场衍射波前传感、双焦面像差反演以及局部可辨识性分析的交互式桌面实验室。

在单焦面强度测量中，由于强度丢失了光瞳场的相位信息，许多像差组合（如正负像散、彗差）会产生极度相似甚至不可分辨的焦面光斑；通过引入已知且恒定的双焦面多样性（Phase Diversity Defocus，取固定离焦值 $d = \pm 0.65\lambda$），系统能够有效破除像差符号歧义，显著提升反演逆问题的局部可辨识性。

### 1.1 核心物理与数值规格
- **离散采样**：$64 \times 64$ 规则采样网格。
- **光瞳孔径**：中心坐标 $(32, 32)$，孔径半径 $R = 16\text{ px}$（无中心遮挡圆形光瞳）。
- **多样性离焦**：负焦面 $d = -0.65\lambda$（$Z_{20}$ 离焦多项式），正焦面 $d = +0.65\lambda$。
- **待估计像差**：
  1. $a_{\text{astig0}}$：$0^\circ$ 像散（Zernike 模式 $Z_{22} = \sqrt{6}(u^2 - v^2)$），取值范围 $[-0.15, +0.15]\lambda$。
  2. $a_{\text{comaX}}$：$x$ 向彗差（Zernike 模式 $Z_{31} = \sqrt{8}(3r^2 - 2)u$），取值范围 $[-0.15, +0.15]\lambda$。
  3. $a_{\text{sph}}$：初级球差（Zernike 模式 $Z_{40} = \sqrt{5}(6r^4 - 6r^2 + 1)$），取值范围 $[-0.15, +0.15]\lambda$。
- **反演求解器**：有限差分雅可比矩阵驱动的 Levenberg-Marquardt (LM) 阻尼非线性最小二乘优化器，初值固定为 $[0, 0, 0]$。
- **局部信息矩阵**：在统一参考点求值的高斯-牛顿信息矩阵 $G = J^T J$，给出局部灵敏度特征值与奇异值谱。

## 2. 界面布局总览 (UI Blueprint)

FocusWitness 采用专为宽屏设计的 3 列桌面工作台布局（支持窄屏自适应垂直堆叠）：

```text
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ FocusWitness  焦证仪       预设选择    [造像] [盲解] [取消] [导入] [导出]    当前运行状态 │
├──────────────────────┬──────────────────────────────────────────┬───────────────────────┤
│ 左：光瞳/实验配置    │ 中：证据矩阵（相同分辨率与色标）         │ 右：反演与可信度       │
│ 像散/彗差/球差滑杆   │ 观测焦面(-0.65) 观测焦面(+0.65)        │ 模式 单焦/双焦         │
│ 真值显示开关         │ 重投影(-0.65)   重投影(+0.65)          │ 估计系数、数值残差     │
│ 波前彩色图           │ 残差(-0.65)     残差(+0.65)            │ LM 轨迹与阻尼          │
│ 3种 Z 模式图例       │ 光强对数显示/线性显示、放大倍率       │ 局部信息谱比较         │
├──────────────────────┴──────────────────────────────────────────┴───────────────────────┤
│ 底：物理简化说明、JSON/PNG 导出与可复核数据、无障碍文字替代复制                        │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

1. **顶部导航栏 (Header)**：应用标题、离散规格标注、快速预设切换下拉菜单、核心操作按钮组（[造像]、[盲解]、[取消]）。
2. **左侧栏 (Left Column - 光瞳与实验配置)**：
   - 实验控制面板：预设选择、反演模式选择、真值可见性开关、像差滑杆及精确数值输入框。
   - 光瞳波前图 ($W(u,v)$)：实时渲染光瞳圆形区域内的波前相位起伏彩色热图与 PV/RMS 标量统计。
   - Zernike 模式图例：图解 $Z_{22}$、$Z_{31}$、$Z_{40}$ 的正交多项式解析形式与物理含义。
3. **中央栏 (Center Column - 证据矩阵)**：
   - 并置 6 个核心焦面视图，按行对应：观测焦面（负/正）、当前估计重投影（负/正）、差值残差（负/正）。
   - 统一分辨率与相同对比标度，残差使用统一正负发散标度（[-] 蓝 / [+] 红）。
   - 支持一键切换对数标度 $\log_{10}(I + 10^{-8})$ 与物理线性标度。
4. **右侧栏 (Right Column - 反演与可信度分析)**：
   - 反演控制面板 (FitPanel)：优化状态提示、LM 阻尼轨迹折线图、迭代历史记录表格、迭代回放进度条。
   - 局部证据与可辨识性信息谱 (EvidencePanel)：在双焦拟合估计点对比单焦与双焦高斯-牛顿信息矩阵的特征值与奇异值谱，配有明确的局部可辨识性科学边界警示。
5. **底栏 (Footer - 审计与导出)**：
   - 物理模型假设与简化说明。
   - JSON 案例/报告导出、全景复合证据 PNG 导出、无障碍文本替代说明快速复制。

## 3. 端到端操作指南 (Step-by-Step Workflows)

### 3.1 预设选择与造像 (Generate)
1. **选择预设场景**：
   在「预设像差场景」下拉菜单中选择以下 5 个冻结场景之一：
   - `mixed`：混合像差测试基准（像散 $0.08\lambda$、彗差 $-0.06\lambda$、球差 $0.04\lambda$）。
   - `perfect`：理想无像差光瞳系统（各项均为 $0.00\lambda$）。
   - `astig-only`：纯像散场景（像散 $0.10\lambda$）。
   - `coma-only`：纯彗差场景（彗差 $0.08\lambda$）。
   - `spherical-only`：纯球差场景（球差 $0.08\lambda$）。
2. **微调像差滑杆**：
   通过滑杆或数字输入框在 $[-0.15, +0.15]\lambda$ 范围内调节任意一项像差。
   > [!NOTE]
   > 当真值参数改变时，系统状态会即时变更为 **STALE（失效）**，提示当前观测与拟合不再对应。
3. **点击 [造像 (生成观测)]**：
   系统向后台 Dedicated Web Worker 发送任务，通过真实 Fraunhofer 积分生成负焦面（$-0.65\lambda$）与正焦面（$+0.65\lambda$）的归一化观测光强，重置所有旧的拟合结果，就绪等待求解。

### 3.2 盲解反演 (Blind Solve)
1. **保持真值隐藏**：
   在进入盲解前，确认「真值可见性开关」处于关闭状态（数值显示为 `***`）。
2. **选择求解模式**：
   - **双焦模式 (±0.65λ)**（推荐）：联合两面观测进行非线性拟合。
   - **单焦模式 (-0.65λ)**：仅使用负焦面数据拟合。
3. **点击 [盲解 (LM反演)]**：
   系统启动反演计算，具有如下铁律保证：
   - 初始估计值**严格固定为 $[0, 0, 0]$**。
   - 传给 Worker 的数据**绝不包含真值参数**。
   - 每次接受步均向 UI 实时流式回传步号、阻尼系数 $\lambda_{LM}$、未缩放损失函数 $\mathcal{L}$ 以及当前估计参数。
   - 求解结束后，状态呈现为「已收敛 (converged)」、「达到最大步数 (max_iterations)」或「求解停滞 (stalled)」。

### 3.3 迭代历史回放 (Iteration Playback)
1. 拟合完成后，历史轨迹折线图将展示所有迭代步的 Loss 与阻尼变化（圆形标记为接受步，菱形标记为拒绝步）。
2. 拖动「迭代回放步号」滑块，可将中央证据矩阵的重投影与残差视图切换至历史任意一步的状态进行教学复盘。
3. 点击「恢复最终估计」按钮，即可一键回到最终收敛估计点。
> [!IMPORTANT]
> 回放操作仅变更重投影展示视图，绝对不会篡改最终收敛的拟合结果。

### 3.4 任务取消 (Cancellation)
在耗时拟合或大步数运算过程中，随时可以点击红色 **[取消]** 按钮。Worker 会在下一次事件循环让出点立即终止优化计算，UI 状态变更为「已取消 (cancelled)」，绝不把未完成的任务计为收敛。

### 3.5 揭示真值与误差比对 (Reveal Ground Truth)
点击「真值可见性开关」，界面将解除盲解遮蔽：
- 滑杆数值框恢复明文显示。
- 反演结果表格将列出估计值、参考真值以及绝对误差 $\Delta a_j$。
- 依据 MATH06 黄金准则，在 `mixed` 预设下，双焦盲解的各项像差恢复误差应严格小于 $0.015\lambda$。

### 3.6 局部可辨识性对照 (Evidence Panel)
当双焦拟合完成后，右下角的证据面板将激活，并在**双焦最终估计点这一同一点**计算高斯-牛顿信息矩阵的特征值与奇异值：
- 单焦奇异值谱：$\sqrt{e_1}, \sqrt{e_2}, \sqrt{e_3}$。
- 双焦奇异值谱：$\sqrt{e_1}, \sqrt{e_2}, \sqrt{e_3}$。
- 最小特征值 $\lambda_{\min}(G)$ 与条件数对比。
- **严格边界警示**：局部可辨识性衡量的是局部 Hessian 曲率，绝不可等同于后验概率或全局唯一性。

## 4. 数据导入与导出 (IO Contracts)

### 4.1 导出
- **导出 JSON 案例 (`focuswitness.case/v1`)**：在未执行拟合时点击导出，生成包含光学配置、4096 负/正观测光强及可选真值的标准案例文件。
- **导出 JSON 完整报告 (`focuswitness.report/v1`)**：在拟合完成后点击导出，生成包含完整案例、拟合结果、60 步内迭代轨迹及局部信息谱的科学报告。
- **导出全景证据 PNG**：点击底栏「导出全景证据 PNG」，离线生成 $960 \times 720$ 的全景标度对比图，同图严格采用一致对比度范围。
- **复制无障碍文本替代**：点击「复制图像无障碍文本替代」，系统将图像关键统计（光强峰值、残差极值、RMS）复制为可检索的纯文本。

### 4.2 导入案例
点击「导入」按钮，选择合法的 JSON 文件：
- 系统内置 2 MiB 文件体积上限防护。
- 严格校验数据 Schema、4096 长度以及光强非负和归一化校验。
- **防坏数据保护**：若导入格式不合法，系统显示具体报错信息，当前良好的案例数据完好保留，不发生崩溃或白屏。
- **切案例状态隔离**：导入新案例后，旧拟合结果立即清空，避免跨案例数据污染。

## 5. 快速验证与离线服务运行

FocusWitness 项目可在本地通过 npm 命令直接验证与构建：

```bash
# 1. 完整验收命令（类型检查 + 全量测试 + 生产构建）
npm run verify

# 2. 启动本地纯静态服务器预览构建产物
npm run serve
```

构建产物位于 `dist/` 目录，其中包含独立的 Dedicated Web Worker 代码块（`dist/assets/compute.worker-*.js`），完全脱机运行，无任何远程调用。
